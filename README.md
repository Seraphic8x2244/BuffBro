# BuffBro Vanilla

## What will this addon be?

- Will **require** ClassicAPI.dll
- Spiritual Successor to PallyPower in behavior, but for all classes
- Will be designed for all raid members to run
  - Every player using it will be able to give perfect accurate timers without scanning
  - Raid Leader and Assistant can overview assign buffs
  - Buffing classes will get simple UX for buffing raidmembers
  - All classes will get simple UX feedback on buffs they can expect
  - If buffs are missing, raidmembers will be able to click to remind the assigned buffer
- Will support syncing from other addons for assignments as third party support

## Current Functionality

- Barebones whilst I develop it
- Only supports Paladins
- Currently syncs with PallyPower for assignments
